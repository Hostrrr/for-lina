# For Lina

Маленький сайт-извинение с тремя мини-играми и заказом цветов.

## Dev

```bash
npm install
npm run dev
```

## Финальная картинка

Положи файл сюда:

```
public/finale.jpg
```

Пока файла нет — на экране финала будет плейсхолдер.

## Заказы цветов (Web3Forms)

1. Зарегистрируйся на https://web3forms.com и получи Access Key (укажи свой email).
2. Локально: скопируй `.env.example` → `.env.local` и вставь ключ.
3. На Vercel: Project Settings → Environment Variables → `WEB3FORMS_ACCESS_KEY`.
